# What's New — June 2026

## Guided Language Lab
A more guided way to practice speaking out loud, one line at a time.

- **Guided lessons** — Pick a language, level, topic, and practice goal, then get a short model dialogue before you jump into the live Language Lab.
- **Repeat and score each line** — Practice one dialogue row at a time, see what the browser heard, and get a transcript-match score right on that line.
- **Progress that feels finishable** — Track lines practiced, average score, excellent matches, streaks, and stars as you work through the lesson.
- **Guided Roleplay when you're ready** — After line practice, switch into a live conversation with the co-hosts using the same lesson scaffold.
- **Cleaner learner controls** — Language Lab hides production-studio controls that do not belong in a speaking-practice lesson.

## Collaborative Sessions
Bring real people into the room with your AI co-hosts.

- **Create a room and send a link** — Studio users can create a collaborative session, share a join code or link, and bring guests into the mixer.
- **Everyone can talk live** — Guest speech routes into the host's shared room context so the AI co-hosts can respond to the group.
- **Room banner and participant names** — See who is in the session, including display names for human guests.
- **Room chat** — Collaborators can use lightweight room text chat alongside the live voice session.
- **Host controls** — Hosts can mute, remove, leave, or end a collaborative session from the room controls.
- **Safer guest behavior** — Guests wait when the host is offline, guest disconnects no longer stop the host's queue, and guest VAD interruptions stay local by default.

## Studio Controls
Playback controls are more reliable during live sessions.

- **Pause is now server-backed** — Pause prevents the next ready audio item from starting even if the browser already has buffered audio.
- **Pause After is more dependable** — Let the current audio finish, then hold the queue on the server until you resume.

## Script Mode
More control when editing generated scripts.

- **Add a line** — Add a new blank script line at the end of a draft.
- **Insert below** — Insert a line between existing turns, then keep editing and autosaving as usual.

## AutoMute & Calibration
Better calibration for speaker-and-mic setups.

- **Safer Tune AutoMute** — Calibration now checks that your voice can be separated from co-host echo before saving interruption settings.
- **Better sustained-speech measurement** — The calibration pass pays more attention to held speech instead of soft gaps between words.
- **Clearer diagnostics** — Calibration results include a collapsed diagnostics panel when you need to understand what happened.
